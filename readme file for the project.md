## 📌 Overview

The Indian automobile industry is one of the largest and fastest-growing sectors of the economy. Sales data from automobile companies can reveal valuable insights about customer demand, market trends, economic conditions, and future opportunities.

This project is a complete **Python-based Data Analysis and Machine Learning solution** created to analyze and predict the sales performance of leading Indian automobile companies.

### Companies Included:

- 🚘 Hyundai  
- 🚙 Mahindra  
- 🚗 Maruti Suzuki  

Using historical datasets, this project transforms raw sales records into meaningful insights through:

- Data Cleaning  
- Exploratory Data Analysis  
- Descriptive Statistics  
- Data Visualization  
- Comparative Company Analysis  
- Machine Learning Prediction  

The final outcome helps understand previous market behavior and forecast future sales trends.

---

## 🎯 Problem Statement

Raw sales numbers alone do not provide useful business intelligence. Companies need proper analysis to understand:

- Which company is performing best  
- How sales trends are changing over time  
- Whether demand is increasing or decreasing  
- What future sales may look like  
- How data can support better decision-making  

This project solves these problems using Python.
